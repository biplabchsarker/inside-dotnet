# Self-Check Quiz — Welcome to Inside .NET

1. What are the eleven parts of the Inside .NET series, in order?
2. Name the eleven sections every chapter in this series follows.
3. True or false: This series is optimized for syntax learning rather than runtime internals.
4. What is the very first internals topic the series opens with in Episode 2?
5. Why does the series place "performance considerations" in every chapter rather than as a single dedicated part?

<details>
<summary>Answers</summary>

1. Foundation, Memory, C# & Clean Code, Design Patterns, Dependency Injection, ASP.NET Core, Concurrency, Entity Framework Core, Architecture, Cloud & Production, Becoming an Architect.
2. Introduction, analogy, problem, visual explanation, internal mechanics, C# implementation, common mistakes, performance considerations, interview questions, key takeaways, what's next.
3. False — it's optimized for runtime/internals understanding, assuming syntax fluency already exists.
4. The full source-code-to-CPU execution pipeline: CLR, IL, JIT compilation, assemblies.
5. Because performance is a property of *every* mechanism covered (GC, async, EF Core, architecture), not a separate topic — understanding a mechanism includes understanding its cost.
