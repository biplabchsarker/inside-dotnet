# FAQ — Welcome to Inside .NET

**Q: Do I need to know C# deeply before starting this series?**
A: You should be comfortable writing and running C# code. This series doesn't teach syntax — it explains what happens beneath the syntax you already use.

**Q: Is this series specific to .NET 10, or does it apply to older versions?**
A: Code samples target .NET 10 / C# 14, but the runtime concepts (CLR, GC, JIT, async) apply broadly across modern .NET (Core 3.1+). Version-specific behavior is called out explicitly when it matters.

**Q: Do I need to read the chapters in order?**
A: The series is designed as a progressive build — Foundation before Memory before Patterns before Architecture. You *can* jump to a specific topic, but each chapter assumes the mental models from earlier ones.

**Q: Will there be video or only written content?**
A: The canonical format is written (`article.md` per chapter), with LinkedIn/Medium variants and slide decks planned per chapter. Video is not in scope initially.

**Q: How is this different from Microsoft's own documentation?**
A: Official docs are reference material, optimized for lookup. This series is a narrative, opinionated teaching path — same rigor, different purpose — connecting internals to real code, real mistakes, and real interview questions.
