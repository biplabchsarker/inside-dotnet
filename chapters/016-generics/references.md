# References & Further Reading: Generics Under the Hood

1. **Microsoft Learn: Generics in .NET**  
   https://learn.microsoft.com/en-us/dotnet/standard/generics/

2. **ECMA-335 Common Language Infrastructure (CLI) Specification**  
   Partition II, Section 9: Generics. Metadata tables: `TypeSpec`, `MethodSpec`, `GenericParam`.

3. **CLR via C# (4th Edition)** by Jeffrey Richter  
   Chapter 12: Generics. Detailed analysis of runtime reification, code sharing (`__Canon`), and constraints.

4. **Design and Implementation of Generics for the .NET Common Language Runtime** by Andrew Kennedy and Don Syme (PLDI 2001)  
   The seminal research paper documenting the mathematical and architectural design of .NET generics.

5. **Static Abstract and Virtual Interface Members in C# 11**  
   https://learn.microsoft.com/en-us/dotnet/csharp/whats-new/csharp-11#static-abstract-members-in-interfaces
