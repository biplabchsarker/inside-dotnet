# License

Inside .NET uses a **dual license**, split by content type:

| Content | License | File |
|---|---|---|
| Code samples (every `code/` folder) and automation scripts (`scripts/`) | MIT | [LICENSE-CODE](LICENSE-CODE) |
| Written content, diagrams, and brand assets (articles, platform variants, FAQs, quizzes, images, `assets/`) | CC BY 4.0 | [LICENSE-CONTENT](LICENSE-CONTENT) |

## Why split?

Code samples are meant to be copy-pasted, adapted, and used freely in real projects with minimal friction — MIT is the standard, expected license for that. Written chapters, diagrams, and brand assets represent the project's actual creative and editorial work — CC BY 4.0 allows free reuse (including commercial) but requires attribution, which is the appropriate protection for a body of written/illustrated work this size.

## In short

- Copy-paste any code sample into your own project: **MIT terms** (do what you want, keep the copyright notice if redistributing the code itself).
- Republish, translate, or build on a chapter's writing or diagrams: **CC BY 4.0 terms** (credit "Inside .NET" by Biplab Sarker, link back, note changes).
